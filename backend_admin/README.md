# 🚀 企业级后台管理系统

一个功能强大、界面精美的现代化企业后台管理系统，专为企业设计。

## ✨ 核心功能

### 🎯 智能内容管理
- **一键轮播图管理**：轻松创建企业官网首页轮播图，支持自动播放、手动切换
- **产品展示系统**：完整的产品分类管理，支持多图展示、详情编辑、批量操作
- **企业形象塑造**：专业的企业介绍、使命愿景、发展历程内容管理
- **品牌信息维护**：企业联系电话、联系方式统一管理

### 🔐 企业级安全认证
- **双重登录保障**：支持用户名密码 + AccessKey双重认证方式
- **JWT安全令牌**：企业级安全认证机制，确保数据安全
- **权限精细控制**：基于角色的访问控制，保护敏感数据

### 📊 智能文件管理
- **海量图片处理**：支持批量上传、智能分类、懒加载优化
- **智能预览系统**：一键预览大图，支持缩放、旋转等操作
- **分组管理**：按业务需求灵活分组，提高管理效率
- **自动清理机制**：删除内容时自动清理相关文件，避免存储浪费

### 🎨 现代化用户体验
- **响应式设计**：完美适配电脑、平板、手机等各种设备
- **主题切换**：支持浅色/深色主题，可设置自动切换时间
- **实时反馈**：操作结果即时反馈，提升用户体验
- **直观导航**：功能模块清晰分类，快速定位所需功能

### ⚡ 高性能架构
- **懒加载优化**：图片按需加载，大幅提升页面响应速度
- **分页显示**：智能分页，避免一次性加载过多数据
- **缓存机制**：智能缓存策略，减少服务器压力
- **并发处理**：支持多用户同时操作，系统稳定可靠

## 🏗️ 系统架构

### 后端技术栈
- **FastAPI** - 现代化高性能Web框架，API响应速度极快
- **JWT认证** - 企业级安全认证，数据传输加密
- **Docker容器化** - 一键部署，环境一致性保障
- **Uvicorn服务器** - 异步高性能服务器，支持高并发

### 前端技术栈
- **Vue 3** - 最新一代前端框架，组件化开发
- **TailwindCSS** - 现代化CSS框架，界面美观专业
- **Vite构建** - 极速开发体验，热重载支持
- **Pinia状态管理** - 高效的状态管理，数据响应式

## 🚀 快速开始

### 一键启动（推荐）
```bash
# 使用Docker一键启动
cd api
docker-compose up -d
```

### 传统部署
```bash
# 后端启动
cd api
pip install -r requirements.txt
python start.py

# 前端启动
cd web
npm install
npm run dev
```
