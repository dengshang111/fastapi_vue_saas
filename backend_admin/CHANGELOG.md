# 更新日志

## [2024-01-XX] - 用户管理功能升级

### 新增功能
- **主控面板**：功能模块导航中心，用于在不同功能页面之间切换
- **用户管理页面**：专门用于图片文件管理
- **图片文件管理**：支持图片上传、预览、删除功能
- **懒加载优化**：使用 Intersection Observer API 实现图片懒加载，提升性能
- **分页加载**：支持分页加载图片，避免一次性加载过多图片
- **轮播图限制**：轮播图只能通过文件上传，不再支持网络图片URL

### 修改功能
- **轮播图管理**：
  - 创建和更新轮播图时只能选择已上传的本地文件
  - 删除轮播图时自动删除对应的本地图片文件
  - 移除了"选择已上传文件"功能，改为在用户管理页面统一管理
- **路由调整**：
  - `/dashboard` 路由指向主控面板
  - `/user-manage` 路由指向用户管理页面
  - `/swiper` 路由改为 `/swiper-manage`
  - 更新了相关页面中的路由链接

### 技术优化
- **性能优化**：
  - 图片懒加载：只有进入视口的图片才会加载
  - 分页显示：每页显示24张图片，支持"加载更多"
  - 图片预览：支持大图预览功能
- **用户体验**：
  - 图片网格布局，响应式设计
  - 悬停显示操作按钮（预览、删除）
  - 文件大小格式化显示
  - 加载状态和空状态提示

### 后端API
- **新增接口**：
  - `GET /api/swiper/uploaded-files` - 获取已上传文件列表
- **修改接口**：
  - `POST /api/swiper/` - 创建轮播图（仅支持filename参数）
  - `PUT /api/swiper/{id}` - 更新轮播图（仅支持filename参数）
  - `DELETE /api/swiper/{id}` - 删除轮播图（同时删除文件）

### 前端组件
- **新增页面**：
  - `UserManageView.vue` - 用户管理页面
- **修改组件**：
  - `DashboardView.vue` - 改为主控面板，提供功能模块导航
  - `SwiperManageView.vue` - 移除已上传文件选择功能
  - `ImageUpload.vue` - 优化上传成功回调
  - `router/index.js` - 更新路由配置

### 测试脚本

## 使用说明

### 主控面板功能
1. **功能导航**：提供图片文件管理、轮播图管理、系统设置等功能模块入口
2. **系统信息**：显示当前用户信息、登录时间、系统状态等

### 用户管理页面功能
1. **图片上传**：点击"上传图片"按钮，选择图片文件上传
2. **图片预览**：点击图片上的眼睛图标预览大图
3. **图片删除**：点击图片上的垃圾桶图标删除文件
4. **懒加载**：滚动页面时，只有进入视口的图片才会加载
5. **加载更多**：点击"加载更多"按钮加载更多图片

### 轮播图管理
1. **创建轮播图**：必须先上传图片，然后选择已上传的图片文件
2. **更新轮播图**：只能选择已上传的图片文件
3. **删除轮播图**：删除轮播图时会同时删除对应的图片文件

### 性能优化说明
- **懒加载**：使用 Intersection Observer API 检测图片是否进入视口
- **分页**：每页显示24张图片，避免一次性加载过多图片
- **预加载**：提前50px开始加载图片，提升用户体验
