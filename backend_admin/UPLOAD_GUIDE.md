# 文件上传功能使用指南

## 功能概述

系统现在支持本地图片上传功能，您可以通过以下方式上传图片：

1. **拖拽上传**：直接将图片文件拖拽到上传区域
2. **点击选择**：点击上传区域选择本地图片文件
3. **手动输入URL**：直接输入图片的网络地址

## 支持的文件格式

- **JPG/JPEG**
- **PNG**
- **GIF**
- **WebP**

## 文件大小限制

- 最大文件大小：**10MB**
- 建议图片尺寸：**800x400** 或更大（用于轮播图显示）

## 使用步骤

### 1. 进入轮播图管理页面

1. 登录后台管理系统
2. 在仪表板点击"轮播图管理"按钮
3. 或者直接访问 `/swiper` 页面

### 2. 添加新轮播图

1. 点击"添加轮播图"按钮
2. 填写轮播图标题
3. 选择图片上传方式：

#### 方式一：本地文件上传
1. 将图片文件拖拽到上传区域
2. 或者点击上传区域选择文件
3. 预览图片确认无误后，点击"上传图片"按钮
4. 等待上传完成

#### 方式二：手动输入URL
1. 在"手动输入图片URL"框中输入图片的网络地址
2. 确保URL可以正常访问

### 3. 设置其他参数

- **排序**：数字越小排序越靠前
- **激活状态**：勾选表示在首页显示

### 4. 保存轮播图

点击"保存"按钮完成轮播图创建

## 图片管理

### 编辑轮播图
1. 在轮播图列表中点击"编辑"按钮
2. 可以重新上传图片或修改其他信息
3. 点击"保存"更新轮播图

### 删除轮播图
1. 在轮播图列表中点击"删除"按钮
2. 确认删除操作
3. 注意：删除轮播图不会删除已上传的图片文件

### 切换状态
1. 点击"激活"或"禁用"按钮
2. 只有激活状态的轮播图会在首页显示

## 技术说明

### 文件存储
- 上传的图片文件存储在 `api/uploads/` 目录
- 文件名使用UUID生成，确保唯一性
- 支持通过 `/api/upload/image/{filename}` 访问

### 安全特性
- 文件类型验证：只允许图片格式
- 文件大小限制：防止大文件上传
- 认证保护：只有登录用户才能上传
- 图片格式验证：使用PIL库验证图片完整性

### 前端特性
- 拖拽上传支持
- 实时预览
- 上传进度显示
- 错误提示
- 响应式设计

## 常见问题

### Q: 上传失败怎么办？
A: 请检查：
1. 文件格式是否为支持的图片格式
2. 文件大小是否超过10MB
3. 网络连接是否正常
4. 是否已登录系统

### Q: 图片显示不出来？
A: 请检查：
1. 图片URL是否正确
2. 图片文件是否存在
3. 网络连接是否正常

### Q: 如何删除已上传的图片？
A: 目前系统没有提供直接删除图片文件的界面，但可以通过API删除：
```
DELETE /api/upload/image/{filename}
```

### Q: 支持哪些图片格式？
A: 支持 JPG、PNG、GIF、WebP 格式的图片文件。

## 开发说明

### API接口

#### 上传图片
```http
POST /api/upload/image
Content-Type: multipart/form-data
Authorization: Bearer {token}

file: [图片文件]
```

#### 获取图片
```http
GET /api/upload/image/{filename}
```

#### 删除图片
```http
DELETE /api/upload/image/{filename}
Authorization: Bearer {token}
```

### 测试脚本

运行测试脚本验证上传功能：
```bash
cd api
python test_upload.py
```

## 注意事项

1. **备份重要图片**：建议定期备份上传的图片文件
2. **磁盘空间**：注意监控服务器磁盘空间使用情况
3. **文件权限**：确保 `uploads` 目录有正确的读写权限
4. **安全考虑**：定期清理未使用的图片文件
