# 小程序二维码功能使用指南

## 功能概述

小程序二维码功能允许管理员在后台设置小程序二维码，并在首页展示给用户。该功能包括：

- 上传小程序二维码图片
- 设置二维码标题和描述
- 启用/禁用二维码显示
- 在首页展示二维码

## 后端API接口

### 1. 获取小程序二维码配置
```
GET /api/qr-code/config
```
需要认证，返回当前配置信息。

### 2. 上传小程序二维码图片
```
POST /api/qr-code/upload
```
需要认证，上传二维码图片文件。

### 3. 更新小程序二维码配置
```
PUT /api/qr-code/config
```
需要认证，更新配置信息。

### 4. 删除小程序二维码图片
```
DELETE /api/qr-code/image
```
需要认证，删除当前二维码图片。

### 5. 获取公开的小程序二维码配置
```
GET /api/qr-code/public
```
无需认证，返回启用的二维码配置。

## 配置文件

配置文件位置：`api/config/小程序二维码/config.json`

```json
{
  "qr_code": {
    "image": "",
    "title": "小程序二维码",
    "description": "扫描二维码体验小程序",
    "enabled": false
  }
}
```

## 前端使用

### 1. 主题设置页面

在主题设置页面（`/theme-settings`）可以：
- 上传小程序二维码图片
- 设置二维码标题和描述
- 启用/禁用二维码显示
- 保存配置

### 2. 首页展示

在首页（`/`）会显示小程序二维码（如果已启用）：
- 显示二维码图片
- 显示标题和描述
- 提供扫码体验提示

## 使用步骤

1. **登录后台管理系统**
   - 访问 `/login` 页面
   - 使用管理员账号登录

2. **进入主题设置**
   - 在仪表板点击"系统设置"
   - 或直接访问 `/theme-settings`

3. **上传二维码图片**
   - 点击"选择图片文件"
   - 选择小程序二维码图片
   - 支持 JPG, PNG, GIF, WebP 格式，最大 5MB

4. **配置二维码信息**
   - 设置二维码标题
   - 设置二维码描述
   - 启用二维码显示

5. **保存配置**
   - 点击"保存二维码设置"
   - 配置将保存到后台

6. **查看效果**
   - 访问首页查看二维码展示效果
   - 二维码只在启用时显示

## 技术实现

### 后端实现
- 使用 FastAPI 框架
- 配置文件存储在 `api/config/小程序二维码/` 目录
- 图片文件存储在 `api/uploads/` 目录
- 支持文件上传和配置管理

### 前端实现
- 使用 Vue 3 + Composition API
- 响应式设计，支持深色模式
- 实时配置更新
- 友好的用户界面

## 注意事项

1. **文件大小限制**：二维码图片最大 5MB
2. **文件格式**：支持 JPG, PNG, GIF, WebP
3. **权限控制**：配置管理需要管理员权限
4. **公开访问**：首页二维码展示无需认证
5. **自动启用**：上传图片后会自动启用二维码显示

## 故障排除

### 常见问题

1. **图片上传失败**
   - 检查文件大小是否超过 5MB
   - 检查文件格式是否支持
   - 检查网络连接

2. **配置保存失败**
   - 检查登录状态
   - 检查网络连接
   - 检查服务器状态

3. **首页不显示二维码**
   - 检查是否已启用二维码显示
   - 检查是否已上传图片
   - 检查配置是否正确
